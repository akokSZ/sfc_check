# SFC / DISM - Утилита проверки целостности системных файлов

## Описание

Автоматизированная утилита для проверки и восстановления повреждённых защищённых системных файлов и хранилища компонентов Windows.

**Версия:** 0.1  
**Автор:** SafeZone.cc  
**Совместимость:** Windows 7 SP1+ (PowerShell 2.0+)

---

## Возможности

- **SFC /scannow** — стандартная проверка и восстановление системных файлов
- **Расширенный цикл восстановления** — автоматическая последовательность: SFC → DISM → SFC
- **DISM /CheckHealth** — быстрая диагностика состояния хранилища компонентов
- **DISM /RestoreHealth** — восстановление хранилища компонентов (требуется интернет или установочный ISO)
- **DISM /StartComponentCleanup** — очистка хранилища WinSxS
- **DISM /AnalyzeComponentStore** — анализ размера и состояния хранилища WinSxS
- **Анализ CBS.log** — вывод значимых строк [SR] и сохранение сырого лога для ручного анализа
- **Открытие папок с логами** — быстрая навигация в папки CBS, DISM и каталог скрипта
- **Сведения о системе** — вывод информации о системе и точках восстановления, сохранение в отдельный лог
- **Справка** — пояснения по результатам SFC и работе утилиты

---

## Логи

Утилита сохраняет:

- `sfc_summary_YYYYMMDD_HHMMSS.log` — сводка с итоговыми статусами
- `sfc_raw_YYYYMMDD_HHMMSS.log` — отфильтрованные строки [SR] из `CBS.log`
- `sfc_pcinfo_YYYYMMDD_HHMMSS.txt` — информация о системе и точках восстановления

---

## Требования

- Права **Администратора** (скрипт проверяет это автоматически)
- PowerShell 5.0+ (Windows 7+)
- Для DISM /RestoreHealth: подключение к интернету или установочный ISO Windows

---

## Установка

1. Сохраните файл `sfc-check.ps1` и вспомогательный `sfc-check.bat` в одну папку
2. Запустите `sfc-check.bat` от имени Администратора

## Меню

При запуске отображается главное меню с пунктами:

- `[1]` Стандартная проверка и восстановление (SFC /scannow)
- `[2]` Расширенная проверка и восстановление (SFC → DISM → SFC)
- `[3]` Быстрая проверка хранилища компонентов (DISM /CheckHealth)
- `[4]` Восстановление хранилища компонентов (DISM /RestoreHealth)
- `[5]` Очистка хранилища WinSxS (DISM /StartComponentCleanup)
- `[6]` Анализ размера хранилища WinSxS (DISM /AnalyzeComponentStore)
- `[7]` Открыть папки с логами
- `[8]` Сведения о системе
- `[9]` Справка
- `[0]` Выход
